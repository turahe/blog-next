# Scroll World Storyboard

## 1. Overview

### Purpose

Create a cinematic introduction for the personal developer portfolio.

The Scroll World should communicate the journey:

```text
IDEA
  ↓
CODE
  ↓
SYSTEM
  ↓
INFRASTRUCTURE
  ↓
PRODUCT
```

The experience should make the visitor feel as if they are moving through a software engineering environment.

The Scroll World is a visual storytelling layer.

It must NOT replace the semantic HTML content of the page.

---

# 2. Experience Goals

The visitor should understand:

1. This is a software engineer.
2. The developer works across frontend, backend, databases, and infrastructure.
3. The developer thinks in systems, not only UI.
4. The developer builds software to solve real problems.
5. The portfolio contains projects and technical writing.

---

# 3. Experience Duration

Target experience:

```text
Desktop:
~20–30 seconds of continuous scrolling

Tablet:
~15–20 seconds

Mobile:
Static/lightweight fallback
```

The exact duration depends on the generated assets.

Do not force visitors to wait through an animation before accessing content.

---

# 4. Global Visual Direction

## Style

Cinematic technology documentary.

Characteristics:

* Dark
* Minimal
* Premium
* Technical
* Atmospheric
* Realistic
* Editorial
* Subtle futuristic elements

Avoid:

* Cyberpunk neon
* Excessive holograms
* Generic AI imagery
* Sci-fi spaceship aesthetics
* Excessive particles
* Gaming aesthetics

---

# 5. Global Camera Direction

The camera should generally move:

```text
FORWARD
   ↓
THROUGH
   ↓
INTO
   ↓
OUT OF
   ↓
TOWARD PRODUCT
```

The camera should feel like one continuous journey.

Avoid frequent:

```text
hard cut
camera reversal
random rotation
```

---

# 6. Global Lighting

Use consistent lighting across scenes.

Primary characteristics:

```text
Low-key lighting
Soft highlights
Deep shadows
Subtle cool-neutral tones
Controlled contrast
```

Avoid dramatically changing color palettes between scenes.

---

# 7. Global Composition

Maintain a consistent camera language.

Preferred:

```text
16:9 desktop
```

Keep important visual subjects away from the extreme edges because UI overlays may appear.

# 9. Scene 01 — The Workspace

## Purpose

Introduce the developer and establish the physical world.

## Scroll Range

```text
0% → 18%
```

## Visual

A modern software engineer workspace at night.

Elements:

* desk
* monitor
* keyboard
* terminal
* code editor
* subtle ambient lighting
* notebook
* architectural sketches

The developer does not need to be clearly identifiable.

The focus is the environment and act of building.

---

```text

```

Movement:

```text
Slow forward dolly
```

Ending:

```text

```

---

## Narrative

Visible HTML content:

```text

```

```text
Software engineer focused on building
reliable software systems and useful products.
```

# 16. Camera Continuity

The following continuity rules are mandatory.

## Direction

Primary camera direction:

```text
FORWARD
```

Avoid abrupt reverse movement.

## Perspective

Maintain:

```text
cinematic perspective
moderate depth
consistent lens feeling
```

## Lighting

Do not change lighting dramatically between scenes.

## Color

Maintain a consistent:

```text
dark
neutral
slightly cool
```

visual language.

---

# 17. Scene Transition Rules

Each transition must answer:

> Why does Scene B logically follow Scene A?

Required transitions:

```text
Workspace
    ↓
Monitor
    ↓
Code
    ↓
Architecture
    ↓
Infrastructure
    ↓
Product
```

Do not use arbitrary scene transitions.

---

# 18. Text Overlay Rules

Text overlays should remain minimal.

Maximum:

```text
1 primary statement
1 supporting statement
```

per scene.

Text should not become a replacement for the actual website content.

---

# 19. UI Overlay

The main navigation may remain visible over the Scroll World.

Recommended:

```text
┌─────────────────────────────────────────────┐
│ Logo             About Projects Blog Contact│
│                                             │
│                                             │
│              SCROLL WORLD                   │
│                                             │
│                                             │
└─────────────────────────────────────────────┘
```

Navigation must remain readable against the visual background.

---

# 20. Scroll Indicator

Optional:

```text
SCROLL
  ↓
```

Use subtle animation.

Do not make it distracting.

It should disappear after the visitor begins scrolling.

# 22. Reduced Motion Storyboard

When:

```text
prefers-reduced-motion: reduce
```

show:

```text
Static hero image
+
Semantic text
+
CTA
```

No camera animation.

No parallax.

No video scrubbing.

---

# 23. Fallback Storyboard

If Scroll World cannot load:

```text
Hero Poster
     ↓
Hero Text
     ↓
CTA
     ↓
Normal Homepage
```

The experience must still feel intentional.

Do not show an empty black area.

# 27. Implementation Constraints

The implementation MUST:

* preserve normal document flow
* avoid blocking initial render
* support keyboard navigation
* support reduced motion
* support mobile fallback
* support static fallback
* preserve semantic HTML
* avoid unnecessary client-side rendering
* avoid loading all scenes immediately
